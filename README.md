<img src="https://github.com/joao-robertoo/projeto-contador/blob/main/projeto-contador.PNG?raw=true"/>
<br>

<h2>👋 Sobre o Projeto</h2>

Este projeto é uma aplicação simples e funcional desenvolvida com HTML, CSS e JavaScript que permite ao usuário definir um início, um fim e um passo para realizar uma contagem dinâmica na tela.

O principal objetivo foi praticar lógica de programação, validações, manipulação do DOM e geração de resultados visuais de forma clara e intuitiva. 
<br> 
<br>

<h2>🧠 O que o Contador faz</h2>

Com este projeto, o usuário consegue:

* Definir um valor inicial
* Definir um valor final
* Escolher o passo da contagem
* Realizar contagens crescentes ou decrescentes
* Exibir o resultado automaticamente na tela com ícones ilustrativos

O foco foi tornar o uso simples e direto, mostrando a contagem de forma limpa e organizada para qualquer tipo de usuário. 
<br> 
<br>

<h2>🧰 Tecnologias Utilizadas</h2>

* **HTML5** — Estrutura da aplicação
* **CSS3** — Estilização simples, responsiva e agradável
* **JavaScript** — Lógica da contagem, validações, DOM e exibição dinâmica
<br>
<br>

<h2>📱 Responsividade</h2>

O layout foi desenvolvido para funcionar bem em:

💻 Computadores
📱 Celulares

Mesmo sendo um projeto simples, a interface se adapta a diferentes tamanhos de tela sem perder a usabilidade. 
<br> 
<br>

<h2>🎯 Objetivo do Projeto</h2>

Este projeto foi criado para aprimorar:

* Lógica de programação
* Estruturas de repetição
* Manipulação do DOM
* Validação de dados
* Organização do código

É um excelente exercício para quem está consolidando fundamentos do JavaScript.

# 🇺🇸 English Version

<h1>⏱️ Project: Counter</h1>

<img src="https://github.com/joao-robertoo/projeto-contador/blob/main/projeto-contador.PNG?raw=true"/>
<br>

<h2>👋 About the Project</h2>

This project is a simple and functional application developed using HTML, CSS, and JavaScript that allows the user to define a start number, an end number, and a step to generate a dynamic counting sequence on the screen.

The main goal was to practice programming logic, validations, DOM manipulation, and the visual presentation of results in a clear and intuitive way. 
<br> 
<br>

<h2>🧠 What the Counter Does</h2>

With this project, the user can:

* Set a starting value
* Set an ending value
* Choose the counting step
* Perform ascending or descending counting
* Display the result automatically with illustrative icons

The focus was to make the experience simple and straightforward, showing the counting process in an organized and user-friendly format. 
<br> 
<br>

<h2>🧰 Technologies Used</h2>

* **HTML5** — Application structure
* **CSS3** — Simple, responsive, and clean styling
* **JavaScript** — Counting logic, validations, DOM manipulation, and dynamic output
<br>
<br>

<h2>📱 Responsiveness</h2>

The layout was designed to work well on:

💻 Desktop devices
📱 Mobile devices

Even being a simple project, the interface adapts well to different screen sizes without losing usability. 
<br>
<br>

<h2>🎯 Project Goal</h2>

This project was created to improve:

* Programming logic
* Loop structures
* DOM manipulation
* Data validation
* Code organization

It’s an excellent practical exercise for anyone consolidating JavaScript fundamentals.
